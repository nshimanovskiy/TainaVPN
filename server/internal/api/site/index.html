Весь трафик — через прокси нужной страны

Tainavpn отправляет трафик всего устройства через прокси: браузер, мессенджеры, игры. Выберите страну в списке и нажмите одну кнопку. Если связь с прокси пропадёт, kill switch не даст трафику уйти напрямую.

Как подключиться

  1. Получите ссылку

    Напишите нашему Telegram‑боту — он выдаст личную ссылку‑подписку и пришлёт приложение.

  2. Установите приложение

    Для Windows, Android или Ubuntu. В приложении нажмите «+ Добавить» → «По ссылке» и вставьте ссылку.

  3. Выберите страну

    В списке появятся прокси нескольких стран с флагами. Выберите любую и нажмите большую кнопку.

Что умеет приложение

Весь трафик, а не только браузер
Работает на уровне системы: в прокси идут все программы, включая те, что не умеют настраивать прокси сами.
Kill switch
Если VPN отключится или приложение упадёт, интернет блокируется, и ваш настоящий адрес не утечёт.
Несколько стран
По одному прокси на каждую страну. Переключение — одним нажатием, флаг и название видно сразу.
Проверка пинга
Кнопка «Пинг» показывает реальную задержку каждого прокси, чтобы выбрать самый быстрый.
DNS без утечек
DNS‑запросы тоже идут через прокси. «Частный DNS» на Android поддерживается.
Обновления в один клик
Приложение само сообщит о новой версии и установит её.
Свои прокси
Можно добавить и собственный SOCKS5 или HTTP‑прокси строкой вида логин:пароль@хост:порт.
Открытый код
В основе — ядро sing-box. Исходный код приложения открыт на GitHub.
